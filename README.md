# Gold Radar XAUUSD

Radar teknikal XAUUSD berbasis browser. Dashboard tidak menggunakan data harga simulasi; jika sumber candle belum terhubung, status akan menunjukkan kegagalan data.

## Deploy
Workflow GitHub Pages ada di `.github/workflows/deploy.yml`. Pada repository settings, pilih Pages → Build and deployment → GitHub Actions jika belum aktif.

## Catatan data
Feed candle publik masih perlu disambungkan ke endpoint historis candle yang kompatibel dan diuji. Jangan anggap sinyal valid saat indikator menampilkan data kosong atau feed terputus.
